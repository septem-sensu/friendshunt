Class: BatteryTracker

BatteryTracker

Geo Battery Class for the Friends Hunt App. This Class represents the Battery Tracker Class for the Friends Hunt App with his Properties and Methods. The Class is for handling Battery Level and is charging. Unfortunately, accessing the battery does not work on the iPhone.
