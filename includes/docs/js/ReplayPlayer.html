ReplayPlayer

This class represents the ReplayPlayer class with all necessary properties, methods and event handlers. The Replay class uses the tracking data to create a replay of all players on the map at multiple speeds.

startHighlight(playerId, highlightTimestamp, timelineIndex)

This method can be used for highlights, it sets the timeline by 5 tracking points of the passed player back, reduces the speed, sets the center of the map on the passed player and zooms in on this point. The “camera” then moves back to the starting point and leaves the replay in the expire old speed.
Parameters:
Name Type Description
playerId string The ID of the player this highlight is about
highlightTimestamp number The timestamp of the timeline to the normal timeline was interrupted
timelineIndex number The index of the timeline where the highlight was started
Returns:
Type
void
Example
replayPlayer.startHighlight( 'max@musterman.de', 1782150381, 378 );
