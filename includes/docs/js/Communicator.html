Class: Communicator

Communicator

This communication class for the app. All requests go through this class. The class contains all required properties and methods. The class requires the Validator class.

flushOfflineQueue()

This method flushes all queued offline tracking data to the server. The requests are sent as fire-and-forget (the response is not processed) so that the map is not updated with old positions.
Returns:
Type
void
Example
